# CPX Study

CPX 실기 준비용 정적 사이트. CC별 **가이드 전문**과 **인출 카드**를 한 곳에서 보고,
진행률이 기기에 저장되며, 홈 화면에 설치하면 오프라인에서도 열립니다.

현재 들어 있는 것 — **관절 · 근골격 · 피부 파트 4개 CC, 카드 196장**

| CC | 제목 | 덱 | 카드 |
|---|---|---|---|
| 25 | 관절 통증 · 부기 | 5 | 58 |
| 26-1 | 목 통증 | 5 | 43 |
| 26-2 | 허리 통증 | 5 | 46 |
| 27 | 피부 발진 | 5 | 49 |

## 1. 올리기 (한 번만 하면 됩니다)

PWA는 주소가 있어야 홈 화면에 설치됩니다. `file://` 로 직접 열면 서비스워커가
등록되지 않아 설치 버튼도, 오프라인도 동작하지 않습니다.
**컴퓨터에서 한 번만** 아래를 하면 끝입니다.

### GitHub Pages (무료 · 영구)

1. github.com 에서 새 저장소를 만듭니다. 이름은 `cpx` 같은 걸로, **Public**.
2. 저장소 화면에서 `Add file` → `Upload files`.
3. **이 폴더 안의 내용물 전체**를 끌어다 놓습니다.
   (`cpx-site` 폴더째가 아니라, 그 안의 `index.html` · `assets` · `data` · `guides` · `icons` …)
4. `Commit changes`.
5. `Settings` → `Pages` → Source 를 `Deploy from a branch`,
   Branch 를 `main` / `/ (root)` 로 두고 저장.
6. 1~2분 뒤 `https://아이디.github.io/cpx/` 로 열립니다.

### 대안

- **Netlify Drop** — app.netlify.com/drop 에 폴더를 끌어다 놓으면 주소가 바로 나옵니다.
- **Cloudflare Pages** — 같은 방식. 둘 다 계정이 필요합니다.

---

## 2. 홈 화면에 설치

주소로 연 다음,

- **iPhone (Safari)** — 아래 공유 버튼 → `홈 화면에 추가`
- **Android (Chrome)** — 주소창 옆 메뉴 → `앱 설치` 또는 화면에 뜨는 안내에서 `추가`

설치하면 주소창 없이 전체화면으로 열리고, 비행기 모드에서도 카드와 가이드가 다 보입니다.

---

## 3. 진행률

- 카드마다 **외웠다 / 다시**를 누르면 이 기기의 브라우저에 저장됩니다.
- 홈 화면 아래 **내보내기**로 파일을 받아 두면 다른 기기에서 **불러오기**로 옮길 수 있습니다.
- 브라우저 방문 기록을 지우거나 시크릿 모드로 열면 사라집니다.

---

## 4. 세 가지 보는 방법

CC 하나마다 버튼이 셋입니다.

| | 무엇 | 언제 쓰나 |
|---|---|---|
| **학습** | 가이드 본문을 파트 → 절로 접었다 펴며 읽습니다. `왜 ~일까요?` 질문은 **탭해야 답이 열리고**, 대본 항목은 말할 문장이 가려져 있습니다. 절마다 읽음 표시가 남습니다 | 처음 이해할 때 · 다시 읽을 때 |
| **카드** | 앞면만 보고 전부 말해내는 인출 드릴. 외웠다 / 다시로 표시하고 못 외운 것만 다시 돌립니다 | 외웠는지 확인할 때 |
| **PDF** | 인쇄용 원본. 그대로 내려받습니다 | 종이로 볼 때 |

학습모드의 진도와 카드의 진도는 **따로 저장**됩니다. 둘 다 홈의 내보내기에 포함됩니다.

## 5. 구조

```
index.html              홈 — 파트별 CC 목록 · 전체 진행률 · 검색
decks.html?cc=…         한 CC의 덱 목록
cards.html?cc=…&d=…     카드 학습 (i= 로 특정 카드에서 시작)
read.html?cc=…&p=…      학습모드 — 가이드 본문을 클릭하며 읽기
guide.html?cc=…         가이드 전문 뷰어 (스크롤형)

assets/style.css        디자인 정본 (버건디)
assets/store.js         진행률 저장 · 데이터 로딩 · 설치 안내
assets/fonts/*.woff2    자체 호스팅 폰트 (사용 글자만 서브셋, 총 548KB)

data/index.json         CC 목록 — 여기에 한 줄 추가하면 CC가 늘어납니다
data/{id}.json          CC별 덱과 카드
data/{id}.read.json     학습모드용 본문 (가이드 HTML에서 자동 변환)
guides/*.html|pdf       가이드 전문

manifest.webmanifest    PWA 메타
sw.js                   오프라인 캐시 (파일을 바꾸면 CACHE 값을 올릴 것)
scripts/build.py        데이터·아이콘·sw 생성
scripts/fonts.py        폰트 서브셋
scripts/reader.py       가이드 HTML → 학습모드 JSON
```

## 6. CC 추가하기

구조는 CC가 30개 이상 늘어나도 그대로 씁니다. 추가는 두 단계뿐입니다.

**① `data/{새id}.json` 을 놓는다**

```json
{
  "num": "01",
  "title": "복통",
  "en": "Abdominal pain",
  "decks": [
    {
      "n": "ONE", "t": "감별의 축", "d": "지도 · 관문 · 대축",
      "cards": [
        {
          "f": { "kk": "관문 · GATE", "big": "복막자극징후가<br>있는가",
                 "cls": "lg", "nm": "대축보다 먼저",
                 "mt": "무엇으로 판정하나요?",
                 "chips": ["반동압통", "복벽강직", "장음 소실"] },
          "t": "관문", "n": "급성복증", "c": "",
          "b": "<div class=\"kv\"><b>판정</b><span>…</span></div>"
        }
      ]
    }
  ]
}
```

카드 한 장의 구조

| 자리 | 뜻 |
|---|---|
| `f.kk` | 앞면 맨 위 작은 라벨 |
| `f.big` | 앞면 큰 글씨. `cls` 는 `xl`(한두 글자) · `lg`(제목) · `md`(문장) |
| `f.nm` `f.mt` | 부제와 안내 문구. **답을 흘리지 않게** 씁니다 |
| `f.chips` | 뒷면 맨 위에 뜨는 뼈대 목록. 앞면에는 나오지 않습니다 |
| `t` `n` `c` | 뒷면 헤더의 제목 · 부제 · 우측 라벨 |
| `b` | 뒷면 본문 HTML. `kv` · `grp` · `note` · `table` · `figure`(인라인 SVG) 사용 가능 |

**② `data/index.json` 에 한 줄 추가한다**

```json
{ "id": "ab", "num": "01", "title": "복통", "en": "Abdominal pain",
  "guide": "CPX01_AbdominalPain_Guide", "status": "ready" }
```

- `status` 를 `"soon"` 으로 두면 목록에 흐리게만 보입니다.
- `guide` 는 `guides/` 안의 파일 이름(확장자 제외). 가이드가 없으면 이 값을 빼세요.
- 새 파트를 만들려면 `parts` 배열에 `{ "tag": "PART", "name": "소화기", "ccs": [ … ] }` 를 더합니다.

**③ 마지막으로**

`sw.js` 맨 위의 `const CACHE = 'cpx-v1'` 을 `'cpx-v2'` 처럼 올리고,
`ASSETS` 배열에 새 파일 경로를 추가합니다. 그래야 이미 설치한 기기에서 갱신됩니다.

새 CC의 한글 글자가 폰트 서브셋에 없으면 그 글자만 시스템 기본 글꼴로 나옵니다.
읽는 데는 문제없지만, 맞추려면 `scripts/fonts.py` 를 다시 돌리면 됩니다.
